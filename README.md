# 민정 가계부 — 개인 용돈·부수입 가계부 PWA

광고 없이 쓰는 개인 전용 가계부입니다.

- **개인 전용**: 남편·Firebase 연동이 없고, 기록은 **이 기기의 브라우저(localStorage)** 에만 저장됩니다. 서버로 전송되지 않습니다.
- `더보기 → JSON 백업` 으로 전체 데이터를 파일로 내려받고, `JSON 복원` 으로 옮길 수 있습니다.
- `CSV 내보내기` 는 엑셀에서 바로 열리는 CSV 를 만들어 줍니다.
- 홈 화면에 추가하면 앱처럼 쓸 수 있고(PWA), 한 번 열면 오프라인에서도 동작합니다.

*데이터를 지우지 않는 한 기록은 이 브라우저에만 있습니다. 기기 초기화·브라우저 데이터 삭제 전에는 백업을 권합니다.*
